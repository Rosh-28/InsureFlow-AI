## 💡 Key Takeaways

### The System in a Nutshell
**InsureFlow-AI automates insurance claim processing using AI:**
1. Users apply for claims (fill form + upload docs)
2. Backend runs AI to validate docs + assess risk
3. System either auto-approves or flags for human review
4. Admins review with AI insights and approve/reject
5. Users chat with AI for help understanding claims

### Why This Architecture?
- **Frontend (React)**: Fast, responsive UI for users and admins
- **Backend (Express)**: Handles business logic, orchestrates agents
- **AI Agents (LangGraph)**: Validates docs, scores risk, decides status
- **Gemini API**: Best AI for understanding images + reasoning
- **Python TTS**: Separate service for high-quality speech synthesis
- **JSON Database**: Simple for prototype, easy to migrate

### The Three Agents
- **Document Verifier**: "Do we have all required docs?" (Gemini Vision)
- **Risk Detector**: "Is this claim risky?" (Rules + Gemini)
- **Decision Maker**: "Should we auto-approve?" (Decision logic)

### The Magic Formula
```
Valid Docs + Low Risk = Auto-Approve
Invalid Docs OR High Risk = Manual Review
```
